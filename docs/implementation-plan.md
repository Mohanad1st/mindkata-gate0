# Six reviewable implementation issues

## Slice 1 — Repository and quality harness

Establish the application, scope lock, Claude rules, deterministic loop, CI, synthetic-only boundary, and traceability. Pass when `npm run loop` is green.

## Slice 2 — Scenario shell

Render fixed scenarios, source cards, visible progress, endpoint language, and responsive accessible layout. No database or live AI.

## Slice 3 — Independent judgment

Capture the initial decision and confidence before exposing AI. Preserve the original values in the session receipt.

## Slice 4 — Frame and delegate

Capture objective, constraints, uncertainty, human-owned work, AI-assisted work, and verification plan. Make missing required fields visible and keyboard accessible.

## Slice 5 — Controlled output and final decision

Reveal only the versioned prewritten output, capture evidence checks and final judgment, and create completion evidence without claiming efficacy.

## Slice 6 — Voluntary continuation and facilitator handoff

Offer Mission 2 only after Mission 1 completion, separate start from completion, validate export/delete behavior, run full UAT, and freeze the Gate 0 prototype for observed sessions.

Each issue uses `.github/ISSUE_TEMPLATE/vertical-slice.yml` and must cite the relevant traceability IDs.
