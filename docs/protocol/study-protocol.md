# Gate 0 study protocol summary

## Purpose

Test proposition clarity, recent consequential need, basic usability, voluntary continuation, buyer relevance, and hard commercial progression. This is not an efficacy or cognitive-diagnostic study.

## Session boundary

- Recruit at least eight eligible users and eight qualified buyers.
- Obtain the approved consent before opening the prototype.
- Use synthetic scenarios only.
- Record timing, rescue, comprehension, structured observations, and separate Mission 2 start/completion.
- Never silently change denominators or overwrite source notes.
- A second reviewer checks ambiguous coding where feasible.

## Prototype outcomes

- Mission 1 completion without facilitator rescue.
- Mission 1 completion time.
- Voluntary Mission 2 start.
- Voluntary Mission 2 completion.
- Initial and final judgment artifacts for qualitative review, not automated efficacy claims.
- Issue and accessibility reports.

## Decision rule

Use the locked thresholds in `../scope-lock.md`. Overall Gate 0 passes only if Gate 0A and Gate 0B pass. Any STOP blocks Gate 1. One bounded retest is the maximum.

## Operational source package

The full Version 2.1.1 Gate 0 Execution Starter Kit remains the controlling source for recruitment, consent language, interview scripts, scorecards, priced-offer testing, coding, and decision logs. This repository summary does not replace facilitator training or independent research/privacy review.
